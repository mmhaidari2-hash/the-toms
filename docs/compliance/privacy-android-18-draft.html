New Life UK — privacy notice draft

Intended scope: the Android app, for adults aged 18 and over, in the free build where purchases are not taken. Dated 11 November 2026. This text is new. It is not the in-app Terms, and it is not a claim that an earlier chat draft was approved.

دامنهٔ مورد نظر: اپ اندروید، برای بزرگسالان ۱۸ سال به بالا، در ساخت رایگانی که پرداخت نمی‌گیرد. تاریخ ۱۱ نوامبر ۲۰۲۶. این متن تازه است. شرایط استفادهٔ داخل اپ نیست و نمی‌گوید پیش‌نویس قبلیِ گفتگو تأیید شده است.

1. What this notice covers

It describes the Android app named New Life UK (package app.thetoms.newlifeuk). The browser build is a different program. It is outside this notice. This page does not describe browser speech, browser storage, or a public website.

این متن اپ اندروید با نام New Life UK را وصف می‌کند. ساخت مرورگر برنامهٔ دیگری است و بیرون از این اطلاعیه است. گفتار مرورگر، ذخیرهٔ مرورگر، یا وب‌سایت عمومی اینجا شرح داده نمی‌شود.

3. Who the app is for

The intended audience of this version is adults aged 18 and over. The app does not check a person’s age. A new profile is an adult profile. A child profile already stored on the device remains, with its existing kid-mode limits. Those limits hide some adult routes, including visa, settlement, forms, driving and the invite control. Switching profiles is not age verification and is not a lock for a parent or carer. An existing child profile is not converted into an adult profile. This draft is not a finished children’s-data assessment.

مخاطب این نسخه بزرگسالان ۱۸ سال به بالاست. اپ سن را بررسی نمی‌کند. پروفایل تازه بزرگسال است. پروفایل کودکی که از قبل روی دستگاه است می‌ماند و محدودیت حالت کودک را نگه می‌دارد. تعویض پروفایل بررسی سن یا قفل والد نیست. پروفایل کودک موجود به پروفایل بزرگسال تبدیل نمی‌شود. این پیش‌نویس ارزیابی تمام‌شدهٔ دادهٔ کودکان نیست.

4. What is stored on the device

The app does not create a learner account and does not upload the profile to a server of ours. Progress, saved words, the diary, settings, profile names and certificate names are kept in a local store on the device. There is no learner database of ours described in this source.

On Android that store is encrypted with a key kept in the device key store. If the key cannot be read, the app shows a bilingual screen and does not delete the saved file and does not write a replacement key. That behaviour is not a certificate that the data is safe against every risk.

The release manifest sets backup off and adds rules that exclude the app’s data domains from cloud backup and from device-to-device transfer. That was checked on the merged manifest, not by moving a handset. It is not a complete security claim.

اپ حساب یادگیرنده نمی‌سازد و پروفایل را به سرور ما نمی‌فرستد. پیشرفت، واژه‌ها، دفترچه، تنظیمات، نام پروفایل و نام گواهی در ذخیرهٔ محلی دستگاه می‌ماند. پایگاه یادگیرندهٔ ما در این سورس نیست.

روی اندروید آن ذخیره با کلیدی در مخزن کلید دستگاه رمز می‌شود. اگر کلید خوانده نشود، صفحهٔ دوزبانه می‌آید و فایل ذخیره‌شده پاک نمی‌شود و کلید تازه نوشته نمی‌شود. این رفتار گواهی امنیت کامل نیست.

مانیفست release پشتیبان را خاموش می‌کند و قاعده‌هایی دارد که دامنه‌های داده را از پشتیبان ابری و از انتقال دستگاه به دستگاه کنار می‌گذارد. این روی مانیفست ادغام‌شده دیده شد، نه با جابه‌جایی یک گوشی. ادعای امنیت کامل نیست.

5. Microphone and speech on this Android app

The installed Android app does not transcribe speech and does not record the learner. Speech recognition and recording are switched off in the Android source. The app manifest source does not request a microphone permission. Optional speech in a browser is not a feature of this Android build and is not promised here.

اپ نصب‌شدهٔ اندروید گفتار را به متن تبدیل نمی‌کند و یادگیرنده را ضبط نمی‌کند. تشخیص گفتار و ضبط در سورس اندروید خاموش است. مانیفست اپ مجوز میکروفون نمی‌خواهد. گفتار اختیاری مرورگر قابلیت این ساخت اندروید نیست و اینجا وعده داده نمی‌شود.

6. Network

The app uses the Internet to download lesson files and pre-rendered voice clips that are not already in the install. The address in source is https://mmhaidari2-hash.github.io/the-toms/assets/. Cleartext HTTP is off. Those clips were made earlier. Playing them does not send the learner’s voice to the speech service that made them.

The host can see a normal download request, which may include an IP address. This app does not contain code that collects that host’s logs. This draft does not state a retention period for those logs, and it does not decide a lawful basis or an international-transfer arrangement. Both are still open.

Fonts used by the app are packaged with it. The source turns runtime font download off.

Links to GOV.UK, the NHS or an English-test site open only when the learner taps them. Those sites are not operated by this app.

اپ برای فایل درس و کلیپ صدایی که از قبل داخل نصب نیست از اینترنت استفاده می‌کند. نشانی در سورس همان میزبان گیت‌هاب است. HTTP بدون رمز خاموش است. پخش این کلیپ‌ها صدای یادگیرنده را به سرویس سازنده نمی‌فرستد.

میزبان می‌تواند درخواست معمولی دانلود را ببیند که ممکن است نشانی IP داشته باشد. این اپ کدی برای گرفتن گزارش آن میزبان ندارد. مدت نگهداری آن گزارش، مبنای قانونی، و ترتیبات انتقال بین‌المللی در این پیش‌نویس تصمیم نشده است.

فونت‌ها همراه اپ‌اند و دانلود فونت در زمان اجرا در سورس خاموش است. پیوند به GOV.UK، NHS یا سایت آزمون فقط با لمس یادگیرنده باز می‌شود.

7. Purchases

This free build does not take a payment. The purchase library is still in the app. In the current source the free flag is on and the store key is empty, so the call that configures that library is not reached. The Play billing permission is removed from the free manifest. Illustrative prices on screen are not an offer.

This draft does not say the packaged library never sends data. That was not shown by inspecting network traffic. A later build that turns payments on would need a new notice.

این ساخت رایگان پرداخت نمی‌گیرد. کتابخانهٔ خرید هنوز داخل اپ است. در سورس فعلی پرچم رایگان روشن و کلید فروشگاه خالی است، پس فراخوانی پیکربندی آن کتابخانه انجام نمی‌شود. مجوز پرداخت از مانیفست رایگان برداشته شده است. قیمت‌های روی صفحه پیشنهاد فروش نیستند.

این پیش‌نویس نمی‌گوید کتابخانهٔ بسته‌شده هرگز داده‌ای نمی‌فرستد. ترافیک شبکه برای این ادعا بررسی نشده است. ساخت بعدیِ پولی اطلاعیهٔ تازه می‌خواهد.

8. Share

Share certificate and Invite a friend open the device share sheet only after a tap. The certificate image includes the name the learner typed. The invite text includes a link to the same GitHub Pages host and has no referral code in source. The app does not send that image to a server of ours. These controls are hidden for a child profile.

اشتراک گواهی و دعوت از دوست فقط پس از لمس، برگهٔ اشتراک دستگاه را باز می‌کنند. تصویر گواهی نامی را دارد که یادگیرنده نوشته است. متن دعوت پیوند همان میزبان را دارد و در سورس کد معرف ندارد. اپ آن تصویر را به سرور ما نمی‌فرستد. این دکمه‌ها برای پروفایل کودک پنهان‌اند.

9. Export and delete

Export copies the local progress records to the clipboard as text. That is the portability control the app actually has. It is not a file sent to the publisher.

Delete my data, after a confirmation, clears the saved progress box, including every profile, and then writes a fresh default adult profile. It does not delete the encryption key. It does not delete cached lesson files. The confirmation says there is no server copy to restore. Uninstalling the app is a separate step on the device, outside this button.

خروجی، سوابق پیشرفت محلی را به‌صورت متن در کلیپ‌بورد می‌گذارد. این همان ابزار انتقال است که اپ دارد. فایلی برای ناشر فرستاده نمی‌شود.

«حذف داده‌های من» پس از تأیید، جعبهٔ پیشرفت ذخیره‌شده را، از جمله همهٔ پروفایل‌ها، پاک می‌کند و بعد یک پروفایل بزرگسال پیش‌فرض تازه می‌نویسد. کلید رمز را پاک نمی‌کند. فایل‌های کش درس را پاک نمی‌کند. تأیید می‌گوید نسخهٔ سرور برای بازگرداندن وجود ندارد. حذف نصب اپ گام جداگانه‌ای روی دستگاه است.

10. Requests and rights

UK data-protection law gives people rights against a controller, including a complaint to the ICO at ico.org.uk. This draft does not operate those rights as a service. There is no contact address that receives a request, no clock for an acknowledgement, and no staff process. Those are open decisions, not promises.

For data that stays on the device, the controls above are export and delete, with the limits in section 9. The publisher cannot restore a deleted local box, because this source has no learner copy on a server.

قانون حفاظت داده در بریتانیا در برابر کنترل‌کننده حقوقی می‌دهد، از جمله شکایت به ICO. این پیش‌نویس آن حقوق را به‌صورت یک خدمت اجرا نمی‌کند. نشانی تماسی که درخواست را بگیرد، مهلت تأیید، و فرایند کارکنان وجود ندارد. این‌ها تصمیم بازند، نه وعده.

برای دادهٔ روی دستگاه، ابزارها همان خروجی و حذف بخش ۹ هستند. ناشر جعبهٔ محلیِ پاک‌شده را برنمی‌گرداند، چون این سورس نسخهٔ یادگیرنده روی سرور ندارد.
